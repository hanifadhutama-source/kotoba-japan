# KOTOBA

## Title
KOTOBA — A Japanese Language Adventure

## Tagline
Learn. Explore. Connect.

## Concept

KOTOBA is a 3D educational adventure game that helps Indonesian students learn basic Japanese language and culture through exploration, NPC interactions, quests, and interactive minigames.

The game is evolved from the existing "Kota Kata" project.

IMPORTANT:
KOTOBA is NOT a completely new game.
It is an evolution of the existing Kota Kata codebase.

## Setting

Tokyo, Japan.

The game takes place in a compact stylized Tokyo-inspired environment.

The goal is NOT to recreate the entire city of Tokyo.

Instead, create a small playable Tokyo hub containing several recognizable Japanese locations.

## Player

The player is an Indonesian student exploring Tokyo and learning Japanese through interaction and challenges.

## Core Gameplay Loop

Explore
→ Find NPC
→ Talk
→ Receive Quest
→ Play Minigame
→ Learn Japanese
→ Complete Quest
→ Unlock Next Quest
→ Explore Further

## Educational Focus

Primary:
- Hiragana
- Katakana
- Basic Japanese vocabulary
- Basic expressions
- Simple sentence patterns

Secondary:
- Japanese culture
- Everyday situations
- Communication

## Technical Principle

Preserve existing systems wherever possible.

Do NOT rewrite the game from scratch.

Prefer modifying existing data and extending existing systems over creating duplicate systems.
